# 원본 사이트 분석 노트

원본: https://derek7688.github.io/my-english-trainers/PSE%20Regular/Delta/DayNN/
분석일: 2026-10-15. 원본 HTML은 세션 임시 폴더에 있으며 프로젝트에는 파생 데이터(`data/`)만 있다.

## 구조
- 각 Day 페이지는 **단일 `index.html`**이다. 빌드 도구 없이 Tailwind Play CDN과 바닐라 JS를 쓴다.
- 데이터는 HTML 안의 `const rawData = [ ... ]` 배열이다. 외부 data.js는 없다.
- Day10·Day18은 404다.

| 문장형 | `num, kr, en` | 03~09, 11~13, 17, 19, 20, 16의 일부 |
| 대화형 | `num, a_kr, a_en, b_kr, b_en` | 14, 15, 16의 일부 |

## 대화형 화면 동작 (Day14, 15 기준, Day16 대화 항목 동일)
- 한 세트 = 4국면: ① A 질문(한국어, 생각) → ② A 정답 공개 → ③ B 답변(상단에 A 대사 맥락 박스) → ④ B 정답 공개
- 배지: A 질문 파랑, B 답변 주황, 문장 초록(Day16 문장 항목)
- 버튼 문구: "A 정답 확인", "B 문제 풀기 →", "B 정답 확인", "다음 세트 →"
- 이전 버튼: 국면을 한 칸씩 되돌리고, 세트의 첫 국면이면 이전 세트의 ④ 화면으로 간다
- 직전 항목 표시: `Last: A: … / B: …`
- 진행 표기: `Set n / N` (문장형은 `Step n / N`)
- 자동 재생 타이밍: 대화·혼합 Day 생각 4.0s / 확인 2.5s, 문장형 Day 4.5s / 3.0s
- 누적 반복: 원본은 고정 N(슬라이더 1~8)으로 잘랐다. 그룹 경계와 무관하다.

## 원본 페이지 간 차이
- Day14·15·16은 Day08과 HTML/JS 구조가 다르다(약 160~200줄 차이). 문장형 Day들은 제목·문구 외에 차이가 없다(Day11은 "64개" 문구가 하드코딩된 것뿐).
- Day19는 페이지 표기("총 60문장")와 실제 항목(66개)이 다르다. 앱은 실제 개수를 쓴다.

## 스크래핑 도구
- `tools/scrape-days.js`: rawData 배열을 **코드를 실행하지 않고** 직접 파싱한다. 문자열·주석을 고려한 대괄호 매칭, 객체 단위 파싱, 중복 키 검사.
- 결과: `data/dayNN.json`(항목·형식·출처·경고), `data/days.json`(목록, 404는 `not-found`).
- 검증 방법: 원문 `num:` 개수와 저장 개수 대조, Day08을 기존 `data.js`와 문장 단위로 비교 → 16개 Day 모두 일치.
